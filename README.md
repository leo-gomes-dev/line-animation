# 🌟 Line Animation Neon

Uma animação web moderna e minimalista construída com HTML5 e CSS3 puro. O projeto utiliza variáveis CSS, filtros de matriz de cores (`hue-rotate`), interpolação de movimento suave (`cubic-bezier`) e efeitos de brilho neon para criar um efeito visual abstrato e futurista com quadrados sobrepostos.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e configuração de variáveis inline (`--i`) para controle do delay das animações.
* **CSS3 Avançado:**
  * Animações customizadas (`@keyframes`).
  * Efeitos de desfoque de fundo (`backdrop-filter: blur`).
  * Sombras internas e externas brilhantes (`box-shadow` neon).
  * Filtros de rotação de matriz de cor (`hue-rotate`) para variação cromática automática nos elementos filhos.
  * Efeito de profundidade 3D com `perspective`.

## 📦 Como Executar o Projeto Localmente

1. Clone este repositório ou baixe os arquivos de código.
2. Certifique-se de que os arquivos `index.html` e `style.css` estão na mesma pasta.
3. Dê um duplo clique no arquivo `index.html` para abrir diretamente no seu navegador de preferência.

## 🎨 Principais Melhorias Aplicadas
* **Suavidade:** Substituição do movimento linear rígido por uma curva de transição `cubic-bezier`.
* **Identidade Visual:** Fundo atualizado de preto sólido para um gradiente radial escuro profundo, aumentando o contraste do neon.
* **Efeito Fluido:** Adicionado efeito de rastro gradiente nas linhas deslizantes (`linear-gradient`) em vez de blocos de cor sólida.
